## 실습 1: Q&A 챗봇 만들기

### 접속 주소
Allganize: https://allganize.ai (또는 강사 안내 주소)

### 단계별 순서

```
Step 1. 로그인
  → 강사에게 받은 계정 정보로 로그인

Step 2. 새 에이전트 만들기
  → 대시보드 → "새 에이전트" 버튼 클릭
  → 에이전트 유형: "Document Q&A" 선택

Step 3. 에이전트 설정
  → 이름: "[내 이름] HR 챗봇" 으로 입력
  → 설명: "회사 인사 규정 질문 답변용"

Step 4. 문서 업로드
  → "문서 추가" → 01_sample_hr_policy.md 업로드
  → 인덱싱 완료까지 대기 (30초~1분)

Step 5. 테스트
  → 아래 질문들을 순서대로 입력해보기
```

### 테스트 질문 목록

| 번호 | 질문 | 예상 답변 키워드 | 확인 |
|---|---|---|---|
| 1 | 신입사원 연차는 몇 일인가요? | 11일, 1개월마다 1일 | □ |
| 2 | 병가는 최대 몇 일까지 사용할 수 있나요? | 60일, 유급 30일 | □ |
| 3 | 배우자 출산휴가는 며칠인가요? | 10일, 유급 | □ |
| 4 | 경조사비 신청 방법을 알려주세요 | HR Portal, 증빙서류 | □ |
| 5 | 재택근무 조건이 어떻게 되나요? | 6개월 이상, 주 2일 | □ |

## Alli에게 잘 질문하는 법

Alli는 질문을 잘할수록 더 좋은 대답을 합니다.

### 즉시 사용 가능한 질문 패턴 3가지

**패턴 1 — 역할 + 요청**
```
"당신은 [역할]입니다. [요청 내용]을 [형식]으로 알려주세요."

예) "당신은 HR 전문가입니다.
    육아휴직 신청 절차를 Step 1, 2, 3 형식으로 설명해 주세요."
```

**패턴 2 — 상황 설명 + 요청**
```
"[상황/배경]입니다.
 [구체적으로 원하는 것]을 [분량/형식] 형식으로 작성해 주세요."

예) "협력업체에 납기가 2주 지연된다는 것을 알려야 합니다.
    정중한 사과 이메일을 200자 이내로 작성해 주세요."
```

**패턴 3 — 답변 개선 요청 (후속 질문)**
```
답변이 마음에 들지 않을 때 → "다시 해줘" 대신:

"좋은데 너무 길어. 절반으로 줄여줘"
"어조가 딱딱해. 더 친근하게 바꿔줘"
"결론을 맨 앞에 넣어줘"
"표 형식으로 바꿔줘"
```

### 빠른 참고: 좋은 프롬프트 공식

```
[역할] + [맥락] + [구체적 요청] + [형식 지정]

예시:
"당신은 HR 전문가입니다. [역할]
 2년차 직원이 육아휴직을 신청하는 상황에서 [맥락]
 필요한 서류와 신청 절차를 [구체적 요청]
 번호 목록으로 순서대로 설명해 주세요." [형식]
```

## 실무 도입 3단계 체크리스트

### 1단계: 오늘 이후 (이번 주)
- [ ] 오늘 만든 에이전트 팀원 1명에게 공유하고 피드백 받기
- [ ] 내 업무용 실제 문서로 교체해서 테스트해보기
- [ ] 프롬프트 엔지니어링 가이드 다시 읽기

### 2단계: 1개월 이내
- [ ] 내 업무에 맞는 에이전트 1개 완성하기
- [ ] 팀 내 공용 에이전트 제안하기 (규정 챗봇, 문서 요약 등)
- [ ] AI 답변의 정확도 주기적으로 점검하기

### 3단계: 3개월 이내
- [ ] 팀원들과 에이전트 활용 노하우 공유회 개최
- [ ] 업무 효율 개선 사례 문서화
- [ ] 추가로 필요한 에이전트 유형 발굴
