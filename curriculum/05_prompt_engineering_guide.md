# 프롬프트 엔지니어링 실습 가이드
## AI에게 제대로 질문하는 법 — 비개발자를 위한 실전 가이드

---

## Alli에게 잘 질문해야 하는 이유

Allganize의 AI 에이전트(Alli)는 여러분이 올린 문서를 읽고 대답합니다. 하지만 **같은 문서를 갖고 있어도 질문 방식에 따라 답변 품질이 크게 달라집니다.**

```
[같은 문서, 다른 질문]

질문 A: "연차 알려줘"
→ Alli 답변: "연차 휴가는 근속기간에 따라 다릅니다."  ← 쓸모없음

질문 B: "입사 2년차 직원이 올해 남은 연차를 계산하려면 어떻게 하면 되나요?
         계산 방법과 신청 절차도 함께 알려주세요."
→ Alli 답변: 조건별 계산식 + 신청 단계 + 관련 규정 조항까지 정리  ← 바로 쓸 수 있음
```

Alli는 여러분의 **의도를 추측하지 않습니다**. 원하는 것을 명확히 적을수록 더 정확하고 유용한 답을 줍니다.

### Alli가 잘하는 것 vs 못하는 것

| Alli가 잘하는 것 | Alli가 못하는 것 |
|---|---|
| 업로드된 문서 안에서 정보 찾기 | 문서에 없는 내용 만들어내기 (하면 안 됨) |
| 여러 조건을 동시에 처리하는 요약 | 실시간 인터넷 검색 |
| 지정된 형식으로 정리/변환 | 100% 정확한 수치 보장 |
| 긴 문서를 원하는 구조로 재구성 | 사람의 판단이 필요한 최종 결정 |

> **핵심**: Alli에게 역할, 맥락, 원하는 형식을 알려줄수록 훨씬 좋은 결과가 나옵니다.

---

## 프롬프트란?

**프롬프트(Prompt)** = AI에게 전달하는 지시문 또는 질문

AI는 여러분의 말을 그대로 처리합니다. 모호한 질문에는 모호한 답이 돌아오고, 구체적인 질문에는 구체적인 답이 돌아옵니다.

> 핵심 원칙: AI는 당신의 의도를 추측하지 않습니다. 원하는 것을 정확히 적어야 합니다.

## Part 1 — 좋은 프롬프트의 3요소

### 요소 1: 역할(Role)
AI에게 어떤 전문가로 행동할지 알려줍니다.

```
❌ 나쁜 예: "이메일 써줘"
✅ 좋은 예: "당신은 전문 비즈니스 글쓰기 전문가입니다. 정중하고 간결한 업무 이메일을 작성해 주세요."
```

### 요소 2: 맥락(Context)
배경 정보와 상황을 제공합니다.

```
❌ 나쁜 예: "요약해줘"
✅ 좋은 예: "다음은 1시간짜리 팀 회의를 기록한 회의록입니다. 팀장에게 보고할 목적으로 요약해 주세요."
```

### 요소 3: 구체적 요청(Specific Request)
원하는 형식, 분량, 조건을 명확히 합니다.

```
❌ 나쁜 예: "정리해줘"
✅ 좋은 예: "결정사항, 액션아이템, 담당자, 기한 네 가지 항목으로 나눠서 표 형식으로 정리해 주세요."
```

**프롬프트 2 (좋은 예)**:

```

**프롬프트 3 (심화)**:
```
당신은 경영지원팀 전문 어시스턴트입니다.

요건:
1. 전체 분량 A4 반 페이지 이내
2. 결정사항과 미결사항을 명확히 구분
3. 긴급 처리가 필요한 항목에는 [긴급] 표시
4. 경영진 입장에서 중요도 순으로 정렬

회의록: [내용 붙여넣기]
```

### 실험 C: 이메일 작성

**상황**: 거래처에 납기가 2주 지연될 것 같다는 사실을 알려야 함.

**프롬프트 1 (나쁜 예)**:
```

```

**프롬프트 2 (중간)**:
```
납기가 2주 지연된다고 거래처에 사과 이메일을 써줘
```

**프롬프트 3 (좋은 예)**:
```

[상황]
- 수신: (주)ABC물산 구매팀 박철수 부장
- 발신: 한국테크 영업팀 정우진 과장
- 내용: 부품 공급 차질로 태블릿 Tab8 Pro 납기가 기존 9월 3일에서 9월 17일로 2주 지연
- 원인: 반도체 부품 수급 문제 (해외 공급사 이슈)

[요건]
- 정중하고 전문적인 어조
- 200자 이내로 간결하게
- 제목 포함
- 대안 및 보상 내용 포함
```

## Part 2-B — Alli 대화 흐름 활용 (연속 질문 기법)

Alli는 대화 맥락을 기억합니다. 한 번에 모든 것을 요청하기 어려울 때는 **단계별 대화**로 풀어가세요.

### 기법 1: 단계 나누기 (Chain Prompting)

```
[1단계] "이 회의록에서 결정사항만 뽑아줘"
  → Alli가 결정사항 목록 제공

[2단계] "위 결정사항 중 마케팅팀 관련 항목만 골라줘"
  → Alli가 필터링

[3단계] "선택된 항목들을 임원 보고용 한 줄 요약으로 바꿔줘"
  → Alli가 최종 정리
```

한 번에 세 가지를 요청하는 것보다 이렇게 나누면 훨씬 정확합니다.

### 기법 2: 부족한 답변 개선 요청

Alli 답변이 마음에 들지 않을 때, 그냥 다시 묻지 말고 **무엇이 부족한지 구체적으로 알려주세요**.

```
❌ "다시 해줘" (Alli가 뭘 바꿔야 할지 모름)

✅ "좋은데, 분량을 절반으로 줄이고 결론을 맨 앞에 배치해줘"
✅ "내용은 좋은데 어조가 너무 딱딱해. 좀 더 친근한 말투로 바꿔줘"
✅ "숫자와 날짜가 누락됐어. 원본에서 찾아서 추가해줘"
```

### 기법 3: 출력 형식 지정

Alli에게 원하는 형식을 명시하면 바로 사용 가능한 결과물이 나옵니다.

| 원하는 형식 | 프롬프트에 추가할 말 |
|---|---|
| 표 | "결과를 표 형식으로 정리해줘" |
| 번호 목록 | "번호를 붙여서 순서대로 나열해줘" |
| 이메일 형태 | "수신자, 제목, 본문, 서명 형식으로 작성해줘" |
| 짧게 | "3줄 이내로 요약해줘" |
| 상세하게 | "각 항목마다 이유와 근거를 포함해서 설명해줘" |
| 보고서 형식 | "제목, 배경, 현황, 결론, 권고사항 순서로 작성해줘" |

### 실험 D: Alli에게 같은 내용, 다른 형식 요청 (직접 실습)

HR 규정 챗봇에서 아래 4가지를 차례로 입력해보세요. 형식이 어떻게 달라지나요?

```

## Part 3 — 시스템 프롬프트 (역할 부여)

시스템 프롬프트는 에이전트의 **기본 성격과 규칙**을 설정합니다. 에이전트를 만들 때 한 번 설정하면 모든 대화에 적용됩니다.

### 예시 1: HR 챗봇 시스템 프롬프트

```
당신은 (주)한국테크의 친절한 HR 어시스턴트입니다.

규칙:
1. 반드시 회사 인사 규정집에 근거해서 답변하세요.
2. 확실하지 않은 정보는 "인사팀에 직접 확인하세요"라고 안내하세요.
3. 답변은 친절하고 명확하게, 300자 이내로 작성하세요.
4. 관련 규정의 조항 번호를 함께 안내하세요.
5. 민감한 개인정보는 절대 요청하거나 수집하지 마세요.
```

### 예시 2: 매출 분석 에이전트 시스템 프롬프트

```
당신은 영업 데이터 분석 전문가입니다.

규칙:
1. 제공된 데이터만을 기반으로 답변하세요.
2. 수치는 항상 단위(원, 개)를 함께 표기하세요.
3. 분석 결과에 간단한 인사이트를 한 줄 추가해 주세요.
4. 데이터에 없는 내용을 추측하지 마세요.
5. 표나 목록 형식을 활용해서 보기 쉽게 정리하세요.
```

### 예시 3: 문서 작성 에이전트 시스템 프롬프트

```
당신은 전문 비즈니스 문서 작성 어시스턴트입니다.

작성 원칙:
- 한국어 비즈니스 격식체 사용
- 불필요한 수식어 제거, 간결하게 작성
- 능동태 위주로 작성
- 숫자와 날짜는 구체적으로 명시

주의사항:
- 작성한 내용은 반드시 사람이 검토/수정해야 합니다
- 법적 효력이 필요한 문서는 전문가 검토를 권장합니다
```

## Part 5 — 자주 하는 실수 TOP 5

### 실수 1: 너무 짧고 모호한 질문
```
❌ "정리해줘"
✅ "다음 내용을 항목별로 정리해서 표로 만들어줘 [내용]"
```

### 실수 2: 원하는 형식을 안 알려줌
```
❌ "매출 분석해줘"
✅ "월별 매출을 표로 정리하고, 전월 대비 증감률(%)을 계산해줘"
```

### 실수 3: AI 답변을 무조건 신뢰
- AI는 그럴듯하게 틀릴 수 있습니다 (Hallucination)
- 중요한 수치나 사실은 반드시 원본 자료로 검증하세요
- 특히 날짜, 금액, 법률 조항은 직접 확인 필수

### 실수 4: 한 번에 너무 많이 요청
```
❌ "이 보고서 요약하고, 번역하고, 이메일로 보낼 형식으로 바꿔줘"
✅ 단계별로 나눠서 요청:
   1단계: "이 보고서의 핵심 내용을 3줄로 요약해줘"
   2단계: "위 요약을 영어로 번역해줘"
   3단계: "위 영어 번역을 비즈니스 이메일 형식으로 바꿔줘"
```

### 실수 5: 예시를 안 줌
```
❌ "공지문 써줘"
✅ "아래 예시와 같은 스타일로 공지문을 작성해줘.
   [예시] 안녕하세요, ○○팀입니다. [내용]..."
```
