## 세션 1 — 도입 + AI 개요 (20분)

### 목표
참가자가 AI/RAG의 기본 개념을 이해하고, 오늘 배울 내용이 자신의 업무에 어떻게 연결되는지 체감한다.

### 진행 흐름

**[0:00~0:05] 강사 소개 + 오늘의 목표**
- "오늘은 코딩 없이 AI 에이전트를 직접 만들어 봅니다."
- "3시간 후에는 본인 업무용 챗봇을 가지고 가실 수 있습니다."
- 출석 확인, 노트북/계정 접속 여부 확인

**[0:05~0:12] 생성형 AI란 무엇인가 (슬라이드)**
- ChatGPT vs RAG 챗봇의 차이점 설명
  - ChatGPT: 학습된 일반 지식으로 답변 → 우리 회사 정보 모름
  - RAG 챗봇: 우리가 올린 문서를 읽고 답변 → 사내 규정, 데이터 활용 가능
- 비유 활용: "ChatGPT는 외부에서 온 신입사원, RAG 챗봇은 회사 문서를 다 읽은 베테랑"
- Hallucination(환각) 개념 — "AI도 틀릴 수 있고, 꼭 검증해야 한다"

**[0:12~0:17] Allganize 플랫폼 전체 구조 (화면 공유)**
- 대시보드 → 에이전트 유형 목록 훑어보기
- 오늘 실습할 3가지 에이전트 위치 짚어주기
- 계정 접속 안 된 분 이 시간에 해결

**[0:17~0:20] 질문 받기**
- 간단히 질문 1~2개 받고 다음 세션으로 전환

### 강사 주의사항
- 슬라이드 분량은 5장 이내 유지 (지나치게 이론적으로 가면 집중도 급락)
- "어렵지 않습니다" 메시지를 반복적으로 전달

## 세션 2 — Q&A 챗봇 구축 (45분)

### 목표
사내 문서(규정집/FAQ)를 업로드해서 질문에 답하는 챗봇을 직접 만든다.

### 준비물
- 샘플 문서: `01_sample_hr_policy.md` (사내 규정 문서)
- 샘플 문서: `02_sample_faq.md` (FAQ 문서)
- 실습 질문 목록 (강사 화면에 띄워두기)

### 진행 흐름

**[0:20~0:35] 데모 — 강사가 직접 챗봇 만들기 (15분)**

1. Allganize 로그인 → "새 에이전트 만들기" 클릭
2. 에이전트 유형: **Document Q&A** 선택
3. 에이전트 이름 입력: "HR 규정 챗봇"
4. 문서 업로드: `01_sample_hr_policy.md` 업로드
5. 인덱싱 완료 대기 (보통 30초~1분)
6. 테스트 질문 3가지 시연:
   - "연차 휴가는 몇 일인가요?"
   - "출산휴가 신청 절차를 알려주세요."
   - "회사 경조사비 지원 기준이 어떻게 되나요?"
7. 문서 근거 출처(인용)가 표시되는 것 강조 — "AI가 어디서 찾았는지 알 수 있습니다"
8. 문서 없이 질문했을 때와 비교 — "오늘 날씨 알려줘" → 답 못 함 또는 거절

**[0:35~1:05] 실습 — 참가자 직접 구축 (30분)**

```
실습 순서 안내 (화면에 게시):
1. Allganize 접속 → 새 에이전트 만들기
2. Document Q&A 선택
3. 이름: "[본인 이름] HR 챗봇"
4. 파일 업로드: 01_sample_hr_policy.md 또는 02_sample_faq.md 중 선택
5. 다음 질문들로 테스트:
   - 연차 개수
   - 병가 처리 방법
   - 경조사비 기준
6. 자신만의 질문 2개 추가로 시도
```

- 강사는 순회하며 오류 발생 참가자 지원
- 빠른 참가자: FAQ 문서도 추가로 업로드해서 두 문서 동시 검색 테스트

### 체크포인트
- [ ] 30명 중 80% 이상이 챗봇을 만들고 질문 3개 이상 테스트했는가?
- [ ] 인용 출처 기능 확인했는가?

## 세션 3 — 프롬프트 엔지니어링 (20분)

### 목표
Alli에게 질문하는 방식에 따라 답변 품질이 얼마나 달라지는지 직접 체험하고, 이후 실습에서 바로 활용할 수 있는 기법을 익힌다.

### 핵심 메시지 (세션 내내 반복)
> "Alli는 똑똑하지만, 여러분 머릿속을 읽지는 못합니다. 잘 물어봐야 잘 대답합니다."

### 진행 흐름

**[1:05~1:10] 도입 — Alli는 왜 질문에 민감한가 (5분)**

- "방금 만든 HR 챗봇에 '연차 알려줘'라고 입력해 보세요." (참가자 직접 타이핑)
- 답변 확인 → "이 답변, 바로 쓸 수 있나요?" 질문 던지기
- "이제 이렇게 바꿔보세요:" 화면에 게시:
  ```
  2024년 3월 입사한 신입사원이 올해 12월까지 쓸 수 있는 연차는
  총 며칠인가요? 계산 과정과 신청 방법도 함께 알려주세요.
  ```
- 참가자가 입력 → 답변 비교 → "차이가 느껴지시나요?"
- **강사 멘트**: "같은 Alli, 같은 문서인데 질문을 바꿨더니 완전히 다른 답이 나왔습니다. 이게 프롬프트의 힘입니다."

**[1:10~1:18] 좋은 프롬프트 3가지 기법 (8분)**

**기법 1 — 역할 주기** (2분)
- 화면에 두 프롬프트 나란히 보여주기:
  - `"병가 신청 방법 알려줘"`
  - `"당신은 HR 전문가입니다. 신입사원이 처음 병가를 신청할 때 필요한 서류와 절차를 단계별로 안내해 주세요."`
- Alli에 입력 → 결과 비교

**기법 2 — 형식 지정하기** (3분)
- 화면에 게시:
  ```
  연차 관련 규정을 아래 형식으로 정리해줘.
  
  | 항목 | 내용 |
  |------|------|
  ```
- 결과가 표로 나오는 것 확인
- "이 결과를 그대로 복사해서 보고서에 붙여넣으면 됩니다"
- 추가 예시: "3줄로", "번호 목록으로", "Step 1, 2, 3 형식으로" 등 빠르게 시연

**기법 3 — 대화 이어가기 (Chain)** (3분)
- "Alli는 대화를 기억합니다. 한 번에 다 물을 필요 없어요."
- 시연:
  ```
  1차: "이 문서에서 휴가 관련 항목을 모두 나열해줘"
  2차: (결과 보고) "위 항목 중 유급 휴가만 골라줘"
  3차: "선택된 내용을 신입사원용 안내문으로 작성해줘"
  ```
- "답변이 마음에 안 들면 '다시 해줘' 대신 뭐가 부족한지 알려주세요:"
  - `"좋은데 너무 길어. 절반으로 줄여줘"`
  - `"어조가 딱딱해. 친근하게 바꿔줘"`

**[1:18~1:25] 참가자 실습 (7분)**

화면에 과제 게시:
```
[과제] 자신이 만든 HR 챗봇에서 아래를 순서대로 해보세요.

1. "연차 신청 방법 알려줘" 입력 → 결과 확인
2. 같은 질문을 형식 지정 버전으로 바꿔서 다시 입력
   예: "연차 신청 절차를 Step 1, Step 2 형식으로 설명해줘"
3. 결과가 마음에 안 들면 후속 질문으로 개선 요청
   예: "좋은데 분량을 줄여줘" / "더 친절한 말투로 바꿔줘"
```

- 강사: "가장 만족스러운 결과를 얻은 프롬프트를 채팅창에 공유해 주세요"
- 2~3명 공유한 프롬프트 화면에 띄우고 칭찬 + 분석

### 강사 팁
- 이 세션은 이후 Excel 실습과 추가 에이전트 세션에서 품질 차이를 만드는 핵심
- 참가자가 답변이 이상할 때 "Alli가 잘못했다"가 아니라 "내 질문을 개선하자"는 태도로 전환시키는 것이 목표
- "프롬프트를 잘 쓰는 것 자체가 AI 활용 역량입니다" 메시지 세션 마지막에 반드시 언급

## 세션 4 — Excel 테이블 에이전트 (45분)

### 목표
자연어 질문만으로 Excel 데이터를 조회/계산/요약하는 에이전트를 만든다.

### 준비물
- 샘플 파일: `03_sample_sales_data.csv` (매출 데이터)
- 참가자에게 파일 사전 배포 (채팅창 또는 공유 드라이브)

### 진행 흐름

**[1:35~1:50] 데모 — Excel 에이전트 구축 (15분)**

1. 새 에이전트 만들기 → 유형: **Table Q&A** (또는 Allganize의 해당 메뉴명)
2. 에이전트 이름: "매출 분석 에이전트"
3. 파일 업로드: `03_sample_sales_data.csv`
4. 자연어 질문 시연:
   - "전체 매출 합계는 얼마인가요?"
   - "3월에 가장 많이 팔린 상품 TOP 3는?"
   - "서울 지역 매출이 부산 지역보다 얼마나 많나요?"
   - "월별 매출 추이를 요약해 주세요"
5. 계산식이 자동 생성되는 과정 설명 ("SQL처럼 데이터를 조회합니다")
6. 결과가 틀릴 수 있음 경고 — 중요 수치는 반드시 원본 확인

**[1:50~2:20] 실습 — 참가자 직접 구축 (30분)**

```
실습 순서 안내:
1. 새 에이전트 만들기 → Table Q&A
2. 이름: "[본인 이름] 매출 에이전트"
3. 03_sample_sales_data.csv 업로드
4. 다음 질문들을 순서대로 시도:
   □ "전체 매출 합계는?"
   □ "가장 매출이 높은 달은?"
   □ "상품별 매출 순위 TOP 5"
   □ "2분기(4~6월) 평균 매출은?"
5. 본인이 궁금한 질문 자유롭게 추가
```

- 빠른 참가자 심화: "판매량이 100개 이상이면서 매출이 500만원 미만인 상품은?" (복합 조건 쿼리)

### 체크포인트
- [ ] Table 에이전트 생성 및 CSV 업로드 완료
- [ ] 자연어 쿼리 최소 4개 이상 시도
- [ ] 계산 결과 정확성 검증 개념 이해

## 세션 5 — 추가 에이전트 데모 (25분)

### 목표
업무에 즉시 활용 가능한 추가 에이전트 유형을 빠르게 체험한다.

### 진행 흐름

**[2:20~2:30] 문서 요약 에이전트 (10분)**

- 새 에이전트 → 유형 선택: Text Generation 또는 Summarization
- 샘플 회의록(`04_sample_meeting_minutes.md`) 붙여넣기 또는 업로드
- 프롬프트: "이 회의록을 결정사항, 액션아이템, 담당자, 기한 형식으로 요약해줘"
- 결과 확인 → 같은 회의록을 다른 형식으로 요약 요청 (분량 1페이지 요약 버전)
- 강조: "매주 반복되는 회의록 요약을 AI가 30초에 처리"

**[2:30~2:40] 이메일/공문 작성 에이전트 (10분)**

- 에이전트 유형: Text Generation
- System Prompt 설정:
  ```
  당신은 전문 비즈니스 글쓰기 어시스턴트입니다.
  요청받은 이메일/공문을 정중하고 간결하게 작성합니다.
  한국어로 작성하며, 비즈니스 격식을 유지합니다.
  ```
- 테스트 시나리오 3가지:
  - "납기가 2주 늦어질 것 같다고 거래처에 사과 이메일 써줘"
  - "팀원들에게 이번 주 금요일 회식 공지 써줘"
  - "계약 갱신을 요청하는 공문 초안 써줘"
- "이건 초안입니다. 항상 사람이 검토하고 수정해야 합니다" 강조

**[2:40~2:45] 추가 활용 아이디어 소개 (5분)**
- 고객 문의 분류 에이전트 — "불만/문의/제안" 자동 태깅
- 다중 문서 비교 에이전트 — 계약서 2개 버전 차이점 추출
- 번역 + 요약 에이전트 — 영문 리포트를 한국어 요약으로
- "Allganize에서 이것들을 모두 만들 수 있습니다" 마무리

## 세션 6 — 자유 실습 + 마무리 (15분)

### 진행 흐름

**[2:45~2:55] 자유 실습 (10분)**
- "지금 본인의 업무에 가장 필요한 에이전트를 직접 만들어보세요"
- 강사 + 보조 강사 순회 지원
- 아이디어가 없는 분을 위한 가이드:
  - "가장 많이 받는 반복 질문이 무엇인가요?" → Q&A 챗봇
  - "매주 만드는 보고서가 있나요?" → 요약 에이전트
  - "자주 작성하는 이메일 유형이 있나요?" → 작성 에이전트

**[2:55~3:00] 마무리 (5분)**
- 오늘 만든 에이전트 목록 정리 (화면에 공유)
- 실무 도입 3단계 안내:
  1. 오늘 만든 에이전트 팀원과 공유
  2. 실제 업무 문서로 교체해서 테스트
  3. 개선점 발견하면 프롬프트 수정
- 참가자용 핸드아웃 배포 (`05_participant_handout.md`)
- 질문 받기 + 강사 연락처 공유
